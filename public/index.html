Cataloging System — assign accession IDs and call numbers to work octavos

Run this once to initialize the cataloging system. It will assign accession IDs (1, 2, 3…) to all work octavos in chronological order, compute call numbers, and flag any entries that need a season assigned. Safe to run again — only processes entries without an accession ID.

Shelving Zones — map season codes to physical shelf ranges

Zones are assigned sequentially across all 35 shelves (C1-S1 → C5-S7). Change the shelf count for any zone and the ranges will redistribute automatically. Counts must add up to 35.
